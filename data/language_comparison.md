# Programming Language Feature Comparison (Comprehensive)

The following tables compare key concepts across eight languages: Python 3.12, TypeScript (with Node.js for system tasks), JavaScript (ES6+ with Node.js for system tasks), Java (LTS, compiled against Java 21), Rust, Go, C (C17), and C++ (C++20). Each feature is shown with a concise syntax example or explanation, in the order a working programmer tends to need them. Rows marked `focus:Rust` only appear when Rust is selected.
